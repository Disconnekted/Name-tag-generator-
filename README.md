# Name Tag Generator

Makes printable class name tags (A4 landscape, 5 × 6 per page) from a class list.
Made by Joseph McLaren.

**Use it:** https://disconnekted.github.io/Name-tag-generator-/

- Import a class list (.xlsx / .csv), paste from Excel, or use the *Copy students* button on the attendance page.
- Four tag styles, crop marks for cutting, reprints of single students, Korean / English screen.
- Each teacher picks their name when the tool opens. Their classes are saved in that browser.

Everything runs in the browser. Class lists are never uploaded to this repository.

Includes SheetJS Community Edition 0.18.5, used under the Apache License 2.0.
