# Name Tag Generator

Makes printable class name tags (A4 landscape, 5 × 6 per page) from the TOPIA attendance page.
Made by Joseph McLaren.

**Use it:** https://disconnekted.github.io/Name-tag-generator-/

- Students come from the *Copy students* bookmark on the TOPIA attendance page (Ctrl+V in the tool). A missing student can be typed in under their class.
- Four tag styles, crop marks for cutting, reprints of single students, Korean / English screen.
- Each teacher picks their name when the tool opens. Their classes are saved online in a Google Sheet, so they follow them to any computer (one-time setup: [sync/README.md](sync/README.md)). Until that is set up, classes are saved in that browser.
- Can be installed as a desktop app from Chrome or Edge (Install icon in the address bar).

Everything runs in the browser. Class lists are never uploaded to this repository; online, they go only to the school's own Google Sheet, behind the school password.
